# Follow-on stations

Only Earth, ISS, Mars, and Mission Control belong in the initial playlist. No placeholder scene is advertised as live.

1. **Deep Space Communications:** verify a supported DSN activity source and usage terms before exposing spacecraft links.
2. **Solar Observatory:** NOAA SWPC documented products; preserve issue and validity times, solar-wind history, and forecast uncertainty.
3. **Skywatch:** location-aware sky map, Moon phase and rise/set using validated calculations; no local promises without coordinates.
4. **Asteroid & Comet Watch:** centralized JPL CAD ingestion, source uncertainty, distances, and educational scale; no unsupported impact/collision claims.
5. **Additional planets:** extend the five-stage expedition contract only when useful dated imagery and reference material exist.
6. **COMET briefings:** source-grounded captions, optional narration, and transcript; muted presentation stays complete.
7. **Fleet configuration / event coordination:** authenticated remote controls and related-event highlights after independent consoles pass reliability acceptance.

Orbital follow-up: evaluate CelesTrak OMM/SGP4 with reference propagation tests and large catalog IDs. The first release uses the documented ISS estimate/positions service, with a strict 45-second marker validity window and explicit source identity; it does not claim local propagation or orbital-element-age knowledge.

Before unattended commissioning: complete the two-hour browser soak and 24-hour hardware acceptance in OPERATIONS.md, on the actual gateway, monitors, and encoding computer.
